# VisionTrafficAI
Real-time urban object detection using YOLOv8.
This project implements a Convolutional Neural Network (CNN) using the YOLOv8 model for real-time urban object detection. The system was trained with custom datasets obtained from open-source platforms such as Kaggle and Roboflow, allowing the detection of vehicles, people, and different objects commonly found in urban environments.

The project includes the complete workflow for dataset preparation, image annotation, model training, validation, and real-time testing using a webcam and OpenCV. The main objective is to apply Computer Vision and Deep Learning techniques to improve object recognition in traffic and urban scenarios.

The model was developed in Python 3.11 using the Ultralytics framework and tested with YOLOv8 object detection architectures. Training performance was evaluated through metrics such as accuracy, loss, confidence scores, and confusion matrix analysis.
Technologies Used
- Python 3.11
- YOLOv8 (Ultralytics)
- OpenCV
- Roboflow
- Kaggle Datasets

Features

- Real-time object detection
- Custom YOLOv8 model training
- Webcam inference with OpenCV
- Image annotation and dataset organization
- Urban traffic scene analysis
- Detection visualization with bounding boxes and confidence scores
  
Project Objective

Develop an intelligent Computer Vision system capable of detecting and recognizing urban objects in real time using Deep Learning techniques and convolutional neural networks.
